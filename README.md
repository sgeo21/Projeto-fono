# Site Profissional - Camila de Souza e Castro

## 📖 Sobre o Projeto

Este projeto foi desenvolvido para a disciplina de **Projeto Integrador** do curso superior de tecnologia em **Desenvolvimento de Software Multiplataforma (DSM)** da **FATEC Araras – Antônio Brambilla**.

O objetivo é desenvolver um site institucional para a fonoaudióloga **Camila de Souza e Castro**, apresentando informações sobre sua formação, experiência profissional, áreas de atuação e formas de contato por meio de uma interface simples, organizada e responsiva.

---

## ✨ Funcionalidades

- Apresentação da profissional;
- Seção com informações sobre sua trajetória;
- Exibição dos serviços oferecidos;
- Área de contato;
- Navegação entre seções da página;
- Layout responsivo para diferentes dispositivos.

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

---

## 🎯 Objetivos do Projeto

- Aplicar os conhecimentos adquiridos durante o curso;
- Desenvolver uma interface web responsiva;
- Praticar conceitos de design e experiência do usuário;
- Criar uma solução digital para divulgação profissional.

---

## 📚 Contexto Acadêmico

Projeto desenvolvido como parte das atividades da disciplina de **Projeto Integrador** do curso de **Desenvolvimento de Software Multiplataforma** da **FATEC Araras – Antônio Brambilla**.
